# Pet Wellbeing — zero-cost MVP prototype

## What is included
- Responsive, mobile-first public website
- Home, standards, directory, veterinarian registration, journal and educational draft pages
- Illustrative pet energy calculator with explicit clinical-review warning
- Local front-end interactions only; no backend or data collection is connected
- Pexels CDN image links for prototype photography; review individual image licenses and keep source records before publication

## Important limitations
- The veterinarian directory intentionally contains no invented profiles.
- The registration form does not transmit or store data. Do not collect real personal or professional information until a secure backend/form service and privacy notice are configured.
- No verified profiles, accounts, booking, payments, video consultations or clinical services are active.
- Article content is starter copy and must be reviewed against current veterinary guidance by an appropriately qualified reviewer before public clinical use.
- The energy estimate is illustrative only and is not a validated feeding recommendation.

## Free deployment
1. Create a GitHub repository (e.g. `pet-wellbeing`).
2. Upload all files preserving the directory structure.
3. In repository Settings → Pages, choose deploy from the main branch and root folder.
4. Replace placeholder URLs in `sitemap.xml` and `robots.txt` with the actual GitHub Pages URL.
5. Add the website to Google Search Console after it is published.

## Before launch
- Select a final brand name and check trademarks/domains/social handles.
- Add a secure registration backend and credential verification workflow.
- Add privacy notice, terms, moderation/complaints process and retention policy.
- Review image permissions and maintain credits/source records.
- Clinically review every article, emergency page and calculator.
- Do not enable paid consultations until country/jurisdiction eligibility, payment provider, professional liability and local follow-up are resolved.
